개인정보처리방침

시행일: 2026년 11월 20일

  1. Corp Mail Reader는 계정 소유자 본인의 Gmail 메일을 Google Gmail API의 읽기 전용 권한으로 읽습니다.
  2. 읽은 메일은 소유자 본인의 PC 안에서만 처리합니다. 제3자에게 제공하거나 판매하지 않고, 광고에 쓰지 않습니다.
  3. 로그인 정보(갱신 토큰)는 소유자 PC에 Windows 데이터 보호(DPAPI)로 암호화해 저장합니다.
  4. Google 사용자 데이터의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.
  5. 권한은 Google 계정의 '타사 연결'에서 언제든지 해제할 수 있습니다.

Privacy Policy

Effective: 20 November 2026

  1. Corp Mail Reader reads the account owner's own Gmail through the Gmail API with read-only access.
  2. Mail is processed only on the owner's own computer. It is never shared with or sold to third parties, and never used for advertising.
  3. The refresh token is stored on the owner's computer, encrypted with Windows DPAPI.
  4. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  5. Access can be revoked at any time from the Google Account's third-party connections page.
